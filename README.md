# 🗄️ Relational Database Management & SQL Data Analytics

A comprehensive repository of production-ready SQL scripts, relational database schemas, complex multi-table joins, and data analysis queries developed during technical training at Calibo.

---

## 🎯 Objective
The primary objective of this repository is to demonstrate relational database engineering and SQL analytics capabilities. It covers designing relational database schemas from scratch, enforcing entity integrity with constraints, performing complex data aggregation, and querying business insights across multiple real-world domain databases.

---

## 🛠️ Technologies Used
- **Query Language:** SQL (Structured Query Language - ANSI Standard)
- **Database Engines:** MySQL / PostgreSQL / SQLite
- **Core Database Concepts:** Relational Data Modeling, Primary & Foreign Keys, Normalization
- **Development Tools:** MySQL Workbench, DBeaver, VS Code

---

## ⚙️ Methodology & Query Architecture

The scripts are organized into modular technical competencies:

1. **Database Definition & Schema Architecture (DDL):**
   - Designed normalized relational databases with strict constraints: `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `AUTO_INCREMENT`, and `CHECK`.
2. **Data Manipulation & Transaction Hygiene (DML):**
   - Performed bulk inserts, updates, and integrity-validated record deletions across linked tables.
3. **Advanced Filtering & Aggregation:**
   - Filtered datasets using conditional operators (`WHERE`, `LIKE`, `BETWEEN`, `IN`).
   - Built analytical summaries using `GROUP BY`, `HAVING`, and aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`).
4. **Relational Multi-Table Joins & Unions:**
   - Executed `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`, and `SELF JOIN` queries across 3+ related tables.
   - Combined query outputs using `UNION` and `UNION ALL`.

---

## 📊 Database Case Studies & Practical Implementations

The queries are implemented across specialized domain databases:

- 🏦 **BankDB (Financial Analytics):** Customer account balances, loan management, and transactional audit trails.
- 🏥 **HospitalDB (Clinical Operations):** Patient appointments, doctor consultations, and department utilization metrics.
- 🎓 **CollegeDB (Academic Tracking):** Student enrollment records, course prerequisites, and faculty assignments.
- 📚 **LibraryDB (Catalog & Circulation):** Book inventories, member borrowing histories, and overdue tracking.
- 🏢 **CaliboDB (Enterprise Business Tasks):** Employee records, department budgets, and performance metrics.
